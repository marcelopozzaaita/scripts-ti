# Notas de Linux

## Arquivos
- `ls -la`: lista tudo, inclusive os arquivos ocultos

## Permissões
- `chmod 644 arquivo`: define que o dono pode ler e escrever, e o grupo e os outros só podem ler

## Busca
- `grep -c TEXTO arquivo`: devolve o número de linhas que contêm o texto no arquivo

## Processos
- `ps aux | grep nome`: lista todos os processos e mostra só os que correspondem ao nome
